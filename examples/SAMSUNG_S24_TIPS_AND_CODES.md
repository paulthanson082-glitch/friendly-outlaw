## ADVANCED TIPS & TRICKS

### Performance Optimization
1. **Game Booster Mode**
   - Settings → Gaming Hub → Game Booster
   - Enables enhanced performance during gaming
   - Disables notifications and background apps

2. **RAM Manager**
   - Settings → Apps → App management
   - Close unnecessary background apps
   - Use RAM booster (Settings → Device care → Memory)

3. **Storage Optimization**
   - Settings → Device care → Storage
   - Auto-clean junk files and cache
   - Enable "Optimize storage automatically"

### Display & Vision
1. **Vision Booster**
   - Settings → Display → Vision Booster
   - Increases brightness and contrast in sunlight
   - Adaptive contrast adjustment

2. **Adaptive Refresh Rate**
   - Settings → Display → Adaptive refresh rate
   - Saves battery by adjusting 1-120 Hz dynamically
   - Match apps to their needs

3. **Always-On Display Customization**
   - Settings → Lock screen → Always On Display
   - Customize colors, widgets, and information
   - Set schedules to disable during sleeping hours

4. **Blue Light Filter**
   - Settings → Display → Eye Comfort Shield
   - Reduces blue light at night
   - Schedule automatic activation

### Battery Life Hacks
1. **Power Saving Modes**
   - **Medium Power Saving**: 40% battery reserve, limited performance
   - **Maximum Power Saving**: 10% reserve, grayscale display, extreme throttling
   - Access: Quick Settings or Settings → Battery and device care

2. **Adaptive Battery**
   - Settings → Battery and device care → Battery
   - AI learns app usage patterns
   - Restricts power to unused apps

3. **Background App Restrictions**
   - Settings → Apps → Permissions → Modify system settings
   - Restrict background activity per app

4. **Battery Widget**
   - Add battery widget to home screen
   - Monitor usage by app in real-time

### Camera Pro Features
1. **Expert RAW Mode** (Pro/Pro XL only)
   - Shoot RAW photos with manual control
   - 24-bit color depth
   - Full control over ISO, shutter speed, white balance

2. **Nightography**
   - Enhanced night mode with AI
   - Reduced noise and improved detail
   - 50MP sensor performance

3. **Magic Eraser**
   - Remove unwanted objects from photos
   - Settings → Editor → Tools → Magic Eraser

4. **Real Tone**
   - Accurate skin tone representation
   - Settings → Camera → More settings → Real Tone

5. **Face Unblur**
   - AI-sharpens blurry faces in existing photos
   - Gallery → Edit → Tools → Face Unblur

6. **Portrait Mode Advanced**
   - Adjust blur level after capture
   - Portrait studio with background customization

### Security Features
1. **Knox Security**
   - Real-time malware scanning
   - Secure folder for sensitive files
   - Biometric authentication options

2. **Secure Folder**
   - Settings → Security → Secure Folder
   - Creates encrypted space for files/apps
   - Separate from main device

3. **Knox Vault**
   - Ultra-secure storage for critical data
   - Isolated from main OS
   - Fingerprint/face/PIN protected

4. **Private Share**
   - Share files with time/permission limits
   - Revoke access anytime
   - Gallery → Share → Private Share

5. **Tap to Awaken**
   - Lock screen → Lock screen settings
   - Double-tap to wake (no fingerprint needed)
   - Useful for accessibility

### Productivity Features
1. **Samsung DeX**
   - Connect to monitor/TV for desktop experience
   - Use keyboard and mouse
   - Apps resize to desktop layout
   - Settings → Mobile Connectivity → Samsung DeX

2. **Link to Windows**
   - Mirror phone on Windows PC
   - Control phone from computer
   - Drag-drop files between devices

3. **Quick Share**
   - Fast file transfer between Samsung devices
   - Gallery → Select file → Quick Share
   - Works with Samsung phones, tablets, PCs

4. **Continuity**
   - Start task on phone, finish on tablet/PC
   - Browser tabs sync
   - Clipboard sharing

5. **One-Handed Operation Mode**
   - Settings → Display → One-handed operation
   - Shrink screen for single-hand use
   - Edge panel shortcuts

### Gesture Controls
1. **Palm Swipe to Capture**

2. **Double Tap to Lock**

## TROUBLESHOOTING CODES & RESETS

### Soft Reset
- Hold Power + Volume Down for 10 seconds
- Device reboots without data loss

### Safe Mode
- Hold Power, long-press Power Off
- Hold Volume Down until reboot to Safe Mode
- Only system apps and pre-installed apps run

### Cache Partition Clear
- Power Off
- Hold Power + Volume Up + Bixby
- Release when Samsung logo appears
- Use Volume keys to navigate, Power to select "Wipe cache"

### Factory Reset (via Settings)
- Settings → General management → Reset
- Select "Reset all settings" or "Erase all data"
- WARNING: Irreversible

## COMMON ISSUES & FIXES

**Battery draining fast?**
- Check Settings → Battery → Battery usage
- Look for rogue apps
- Disable background app refresh for culprits

**Phone getting hot?**
- Close intensive apps (games, video streaming)
- Reduce screen brightness
- Enable Power Saving mode
- Check for runaway background processes

**Slow performance?**
- Run Device Care optimization (Settings → Device care → Optimize now)
- Clear cache via Settings → Apps → Cache storage
- Disable unnecessary visual effects
- Restart phone

**WiFi/Bluetooth not connecting?**
- Toggle airplane mode on/off
- "Forget" network and reconnect
- Clear cache for Settings app
