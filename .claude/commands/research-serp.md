# /research-serp

Perform detailed SERP analysis for a specific target keyword.

## Usage
`/research-serp [keyword]`

## What This Command Does

Analyzes the top 10-20 search results for the given keyword:

1. **SERP Features**: identify featured snippets, PAA boxes, local packs, image carousels
2. **Competitor Deep-Dive**: for each top result, analyze title, URL structure, H1, word count, unique angle
3. **Content Patterns**: common sections, formats, and structures in top results
4. **Keyword Variations**: related terms, synonyms, and LSI keywords used by top results
5. **Search Intent**: classify as informational / navigational / transactional / commercial
6. **Featured Snippet Opportunity**: assess if optimizing for position zero is viable

## Output

Save to: `research/serp-[keyword-slug]-[YYYY-MM-DD].md`

## Instructions

Analyze the SERP landscape for "$ARGUMENTS". Identify patterns among top-ranking content and pinpoint opportunities to create something demonstrably better. Focus on what a searcher using this keyword actually wants to find.
