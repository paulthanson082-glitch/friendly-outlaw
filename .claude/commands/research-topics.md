# /research-topics

Research and build out a topic cluster for a pillar keyword.

## Usage
`/research-topics [pillar keyword]`

## What This Command Does

1. **Pillar Content Analysis**: assess the main pillar page opportunity
2. **Cluster Mapping**: identify 8-15 supporting cluster topics
3. **Internal Linking Structure**: map how cluster articles link to pillar and each other
4. **Keyword Assignment**: assign target keywords to each cluster article
5. **Content Calendar**: suggest sequencing for creating cluster articles

## Output

Save to: `research/topic-cluster-[pillar-slug]-[YYYY-MM-DD].md`

## Instructions

Build a comprehensive topic cluster plan around "$ARGUMENTS". Create a pillar-and-cluster content architecture that establishes topical authority. Map the cluster to existing content where possible, and identify new articles needed to complete the cluster.
