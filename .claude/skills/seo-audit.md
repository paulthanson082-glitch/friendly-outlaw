# SEO Audit Skill

Perform a technical and content SEO audit for a page or section of the site.

## Audit Scope Options

### Page-Level Audit
For a single URL or file:
- Title tag and meta description
- Heading structure
- Keyword optimization
- Internal and external links
- Content quality and depth
- Schema markup
- Mobile friendliness indicators

### Content Section Audit
For a set of related articles:
- Keyword cannibalization check
- Topic coverage gaps
- Internal linking opportunities
- Content freshness assessment

### Technical SEO Checklist
- Canonical tags
- Redirect chains
- Duplicate content
- Page speed indicators
- Core Web Vitals considerations

## Usage

Provide:
1. URL(s) or file path(s) to audit
2. Scope (page, section, or technical)
3. Primary concern (rankings, CTR, cannibalization, etc.)

## Output

- Audit findings by priority (critical/high/medium/low)
- Specific action items with implementation guidance
- Estimated impact for each recommendation
