# Signup Flow CRO Skill

Optimize the path from landing page to account creation to reduce friction and increase conversions.

## Signup Flow Components

### Pre-Signup (Landing Page)
- Value proposition clarity
- CTA to signup: copy and placement
- Social proof and trust signals
- Friction reduction (no CC required, free trial, etc.)

### Signup Page
- Headline: benefit-focused, not form-focused
- Field minimization (email only? email + password? OAuth?)
- OAuth options: Google, GitHub, LinkedIn
- Trust signals near form
- Terms and privacy: minimal friction presentation

### Post-Signup
- Welcome screen: confirm value, set expectation
- Immediate next step: clear, single action
- Skip option for optional steps
- Progress indicator if multi-step

### Re-Engagement for Abandoned Signups
- Email: "Did you mean to sign up?"
- Retargeting: remind of value prop
- Personalized follow-up

## Common Friction Points
- Too many required fields
- Email verification before access
- Credit card required for trial
- Complex password requirements
- No OAuth options
- Unclear post-signup next step

## Usage

Provide:
1. Current signup flow (URL or description)
2. Signup conversion rate (if known)
3. Model: free trial / freemium / paid-first
4. Current friction points suspected

## Output

- Signup flow audit with friction scores
- Recommended field changes
- Copy for each step
- Trust element placement
- Abandon recovery recommendations
