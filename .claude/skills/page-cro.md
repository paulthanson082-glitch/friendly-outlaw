# Page CRO Skill

Optimize any page for higher conversion rates using CRO best practices.

## Analysis Areas

### Conversion Funnel Analysis
- Entry point and traffic source alignment
- Friction points in the user journey
- Drop-off point identification
- Goal completion path

### Above-the-Fold Optimization
- Headline clarity and value proposition
- CTA visibility and prominence
- Trust signals in viewport
- Message match with traffic source

### CTA Optimization
- Button copy (action + outcome)
- Visual hierarchy
- Placement and frequency
- Offer attractiveness

### Trust Building
- Social proof placement
- Risk reversal positioning
- Authority signals
- Security indicators

### Copy Optimization
- Benefit vs. feature focus
- Objection handling
- Clarity and reading level
- Tone alignment with audience

## Usage

Provide:
1. Page URL or file
2. Current conversion rate (if known)
3. Traffic source (organic, paid, email, etc.)
4. Conversion goal
5. Primary concern (low CVR, high bounce, low engagement)

## Output

- Prioritized optimization recommendations
- Specific copy rewrites
- A/B test hypotheses
- Expected impact estimates
