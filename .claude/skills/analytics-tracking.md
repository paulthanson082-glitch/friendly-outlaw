# Analytics Tracking Skill

Plan and implement analytics tracking for content performance measurement.

## Tracking Setup

### Google Analytics 4 Events
- Page views (automatic)
- Scroll depth (50%, 75%, 90%)
- Time on page milestones
- CTA clicks
- Form submissions
- Video plays
- File downloads

### Google Search Console Setup
- Property verification
- Sitemap submission
- Performance monitoring
- URL inspection

### Key Metrics by Content Type

**Blog Content**
- Organic sessions
- Avg. engagement time
- Scroll depth
- CTA click rate
- Conversion from content

**Landing Pages**
- Conversion rate
- Form completion rate
- CTA click rate
- Bounce rate
- Traffic source breakdown

### Content Attribution
- First-touch attribution: which content introduced the user
- Last-touch attribution: which content converted the user
- Multi-touch: full journey mapping

## Usage

Provide:
1. What you want to measure
2. Current analytics setup (GA4? GTM? etc.)
3. Conversion goals
4. Content type

## Output

- Measurement plan
- Event tracking specifications
- GA4 or GTM implementation notes
- Dashboard/report recommendations
- KPI targets
