# Schema Markup Skill

Generate structured data (schema.org JSON-LD) for rich search results.

## Schema Types Supported

### Article / BlogPosting
For blog posts and articles — enables rich snippets in Google News.

### FAQPage
For FAQ sections — displays expandable Q&A directly in SERP.

### HowTo
For step-by-step guides — displays steps in rich results.

### Product
For product pages — displays price, availability, reviews in SERP.

### Service
For service pages — helps Google understand what you offer.

### LocalBusiness
For location-based businesses.

### BreadcrumbList
For site navigation breadcrumbs.

### SiteLinksSearchBox
Enables search box in Google results.

## Usage

Provide:
1. Page type and URL
2. Content to encode (title, description, FAQ items, steps, etc.)
3. Schema type needed (or let me recommend)

## Output

Complete JSON-LD schema markup ready to paste into `<head>` or via Google Tag Manager. Includes:
- Valid JSON-LD block
- Placement instructions
- Google Rich Results Test URL
- Notes on what rich result to expect
