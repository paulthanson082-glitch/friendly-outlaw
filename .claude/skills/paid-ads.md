# Paid Ads Skill

Write ad copy and plan paid advertising campaigns for Google, Meta, LinkedIn, and other platforms.

## Ad Formats

### Google Search Ads
- Responsive Search Ads: 15 headlines (30 chars each), 4 descriptions (90 chars each)
- Dynamic keyword insertion considerations
- Ad extensions: sitelinks, callouts, structured snippets

### Meta (Facebook/Instagram) Ads
- Primary text (125 chars visible above fold)
- Headline (27 chars)
- Description (27 chars)
- Image/video creative brief

### LinkedIn Ads
- Single image: headline (70 chars), body (150 chars)
- Sponsored content: headline (70 chars), intro text (150 chars)
- Message ad: subject line, body, CTA

## Copy Frameworks for Ads

### Pain → Solution
"Tired of [problem]? [Product] helps you [solution]. [CTA]."

### Number-led
"[Number] [audience] use [product] to [result]. Try it free."

### Question
"What if you could [desired outcome]? [Product] makes it possible."

### Social Proof
"[X] [audience] choose [product]. Here's why."

## Usage

Provide:
1. Platform(s)
2. Campaign goal: awareness / traffic / conversions / retargeting
3. Target audience
4. Offer or value proposition
5. Landing page URL or brief

## Output

- Multiple ad copy variations per format
- Headline and description options for testing
- Targeting recommendations
- Creative brief for images/video
- A/B testing priority
