# Programmatic SEO Skill

Design and plan programmatic SEO content at scale — templates for high-volume, data-driven pages.

## Use Cases

### Location-Based Pages
"[Service] in [City]" — one template, hundreds of cities.

### Integration/Comparison Pages
"[Product] + [Tool] Integration" — one template, dozens of integrations.

### Use Case Pages
"[Product] for [Industry/Role]" — one template, many segments.

### Data-Driven Roundups
"Best [Category] in [Year]" — template populated with fresh data.

## Template Design Process

1. **Define the head term**: "[Service] in [Location]"
2. **Identify the data source**: spreadsheet, API, database
3. **Map variables**: {city}, {state}, {population}, {local_stat}
4. **Design the template**: sections that work for all variations
5. **Quality threshold**: what minimum data is needed per page?
6. **Internal linking**: hub page → all location pages

## Template Sections to Plan

- H1: dynamic formula
- Introduction: personalized to variable
- Key stats/data: variable-specific
- Social proof: local or relevant
- FAQ: mostly static with variable injections
- CTA: consistent

## Usage

Provide:
1. Head term and variable type (location, integration, industry)
2. Data you have available
3. Number of variations to create
4. Target audience

## Output

- Template structure with dynamic variable placeholders
- Sample populated pages (3 examples)
- Data schema required
- Internal linking plan
- Quality guidelines to prevent thin content
