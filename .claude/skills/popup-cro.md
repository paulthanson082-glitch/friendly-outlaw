# Popup CRO Skill

Optimize exit-intent popups, scroll-triggered popups, and in-app modals for conversion.

## Popup Types

### Exit-Intent Popup
Triggered when user moves cursor toward browser chrome.
- Best for: lead capture, prevent bounce, last-chance offer
- Offer: lead magnet, discount, free trial

### Scroll-Triggered Popup
Triggered after user scrolls 50-70% of the page.
- Best for: content upgrades, newsletter signup
- Offer: related resource, email course, checklist

### Time-Based Popup
Triggered after X seconds on page.
- Best for: engaged visitors
- Offer: webinar, demo, guide

### In-App Modal
Triggered by feature limit, upgrade prompt, or milestone.
- Best for: freemium upgrade, feature discovery
- Offer: upgrade, feature unlock, trial

## Copy Framework

1. **Headline**: specific benefit or question (not "Sign up for our newsletter")
2. **Subheadline**: what they get, for free, right now
3. **CTA**: action verb + specific outcome
4. **Close link**: "No thanks, I don't want [benefit]" (loss aversion)

## What to Avoid
- Generic "Subscribe to newsletter" asks
- Large image that hides the value proposition
- CTA that says "Submit" or "Yes"
- Multiple popups on same visit

## Usage

Provide:
1. Popup type
2. Page where it appears
3. Offer or ask
4. Target audience
5. Current conversion rate (if known)

## Output

- Headline options (5 variations)
- Subheadline options
- CTA button copy options
- Close link copy
- Trigger recommendation
- A/B test recommendations
