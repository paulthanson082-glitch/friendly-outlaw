# Social Content Skill

Repurpose blog content or create original social media posts for any platform.

## Platform Formats

### LinkedIn
- Long-form posts (1,300-2,000 chars)
- Hook → story/insight → takeaway format
- Professional tone, personal voice
- 3-5 hashtags

### Twitter/X
- Thread format (10-15 tweets)
- Hook tweet → value tweets → CTA tweet
- Conversational, punchy
- 1-2 hashtags max

### Instagram
- Caption (150-300 chars above fold)
- Value or story-led
- 5-10 relevant hashtags

### Facebook
- Engagement-focused
- Question or opinion format
- Community-building tone

## Repurposing Approach

From a blog post, extract:
1. Key statistics → data-led posts
2. Step-by-step sections → carousel or thread
3. Expert quotes → quote graphics
4. Conclusions → opinion posts
5. Introduction hook → awareness posts

## Usage

Provide:
1. Source content (blog post, topic, or key message)
2. Platform(s)
3. Goal (awareness, engagement, traffic, leads)
4. Brand voice reference

## Output

Ready-to-publish posts for each platform with format notes and posting recommendations
