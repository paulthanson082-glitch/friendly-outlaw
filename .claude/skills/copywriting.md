# Copywriting Skill

Write conversion-focused copy for any format using proven frameworks.

## Frameworks Available

### AIDA (Attention → Interest → Desire → Action)
Best for: landing pages, email, ads

### PAS (Problem → Agitate → Solution)
Best for: sales pages, email sequences, social ads

### FAB (Features → Advantages → Benefits)
Best for: product descriptions, feature announcements

### Before/After/Bridge
Best for: transformation-focused copy

### 4Ps (Promise → Picture → Proof → Push)
Best for: long-form sales copy

## Usage

Provide:
1. What you're selling or promoting
2. Target audience (check `context/brand-voice.md`)
3. Desired action (sign up, buy, download, etc.)
4. Format (headline, email, landing page section, ad, etc.)
5. Framework preference (or let me choose)

## Output

Deliver copy with:
- 3 headline variations
- Full copy using chosen framework
- CTA options
- Brief explanation of approach
