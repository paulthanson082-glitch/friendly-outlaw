# Form CRO Skill

Optimize forms (signup, contact, lead capture, checkout) for higher completion rates.

## Form Optimization Principles

### Field Reduction
- Remove every non-essential field
- Combine fields where possible (full name instead of first + last)
- Move optional fields post-conversion
- Use progressive profiling (collect data over time)

### Label and Placeholder Best Practices
- Labels above fields (not placeholder text)
- Clear, specific labels ("Work email" not "Email")
- Helper text for complex fields
- Real-time validation (not just on submit)

### Error State Optimization
- Inline errors (not top of form)
- Specific error messages ("Email must include @" not "Invalid email")
- Preserve user input on error

### Trust Near Forms
- Security badge near submit button
- Privacy assurance: "We don't share your data"
- Social proof: "Join X,000 users"
- Risk reversal: "Cancel anytime"

### CTA Button
- Descriptive: "Start Free Trial" not "Submit"
- First person: "Start My Free Trial"
- Benefit-reinforcing: "Get My Free Report"

## Usage

Provide:
1. Form URL or current fields list
2. Form goal (signup, lead, contact, checkout)
3. Current completion rate (if known)
4. Primary drop-off concern

## Output

- Field-by-field audit
- Recommended final field list
- Label and helper text copy
- CTA button options
- Trust element recommendations
- A/B test priority
