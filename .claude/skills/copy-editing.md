# Copy Editing Skill

Edit and improve existing copy for clarity, persuasion, brand voice, and conversion.

## Editing Dimensions

### Clarity
- Remove jargon (or explain it)
- Simplify complex sentences
- Replace passive with active voice
- Eliminate ambiguity

### Persuasion
- Strengthen value propositions
- Add specific evidence and proof points
- Improve benefit framing
- Sharpen CTAs

### Brand Voice
- Align with `context/brand-voice.md`
- Tone consistency throughout
- Vocabulary preferences
- Personality injection

### Conversion Focus
- Reduce friction in copy
- Clarify next steps
- Address objections
- Improve specificity

### Readability
- Sentence length variation
- Paragraph structure
- Heading clarity
- Scannable formatting

## Usage

Provide:
1. Copy to edit (paste it or provide file)
2. Edit type: light touch / standard / heavy revision
3. Priority concern: clarity / persuasion / voice / conversion
4. Target audience and goal

## Output

- Edited version with changes tracked (show before/after for significant changes)
- Editorial notes explaining key decisions
- Suggestions for further improvement if any remain
