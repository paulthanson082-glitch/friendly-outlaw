# Referral Program Skill

Design and write content for customer referral programs.

## Program Components

### Incentive Structure
- Two-sided: reward both referrer and referee
- One-sided: reward referrer only
- Milestone rewards: bonus for multiple referrals
- Recurring rewards: ongoing commission model

### Copy Elements
- Program name and tagline
- How it works (3-step explanation)
- Reward description (clear value)
- Sharing prompt (email templates, social copy)
- Terms summary

### Channels to Drive Referrals
- In-app prompt (best timing: after value moment)
- Email: dedicated announcement + ongoing reminder
- Thank-you page: post-purchase referral prompt
- Account/settings page: always-on

## High-Converting Referral Hooks

- "Give a friend [benefit], get [reward]"
- "You've found something great. Share it."
- "Help a friend [achieve goal] and earn [reward]"

## Usage

Provide:
1. Business type and product
2. Intended reward (credit, cash, discount, free time)
3. Target referral behavior (signup, purchase, upgrade)
4. Channels to promote

## Output

- Program structure recommendation
- Complete copy for all program touchpoints
- Email templates for referral sharing
- In-app prompt copy
- Program landing page brief
