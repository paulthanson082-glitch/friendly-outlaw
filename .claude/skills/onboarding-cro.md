# Onboarding CRO Skill

Optimize user onboarding flows for activation, engagement, and conversion to paid.

## Onboarding Framework

### Activation Goals
Define the "aha moment" — the point where a user first gets core value.
- Identify: what action correlates with retention?
- Minimize: steps to reach that action
- Celebrate: acknowledge when they reach it

### Flow Audit
- Step count from signup to aha moment
- Drop-off points in the flow
- Time to value
- Required vs. optional steps

### Copy for Each Step
- Welcome message (personal, benefit-focused)
- Step instructions (action-oriented, specific)
- Progress indicators
- Help and support touchpoints
- Celebration messages (milestone acknowledgment)

### Email Nurture During Onboarding
- Day 0: Welcome + first action
- Day 1: Tips for quick wins
- Day 3: Feature spotlight
- Day 7: Check-in + support offer
- Day 14: Social proof + upgrade nudge (if freemium)

### Upgrade Prompts
- Trigger: when user hits freemium limit
- Copy: specific benefit gained by upgrading
- CTA: clear, low-friction

## Usage

Provide:
1. Current onboarding flow (steps or URL)
2. Product type (SaaS, marketplace, tool, etc.)
3. Activation metric target
4. Current drop-off data (if available)
5. Freemium or free trial model

## Output

- Onboarding flow audit
- Recommended step sequence
- Copy for each step
- Email sequence for onboarding
- Upgrade prompt copy
- A/B test recommendations
