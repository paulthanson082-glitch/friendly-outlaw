## How to Use This File

- **Pillar keywords**: main topics for cornerstone/pillar content
- **Cluster keywords**: supporting articles that link to pillar content
- **Long-tail**: specific, lower-volume terms often easier to rank
- **Intent**: informational (I), commercial (C), transactional (T), navigational (N)
