💻 CODE EXAMPLE (Swift)

import WritersApp

// Create app with AI enabled
let config = AIConfiguration(apiKey: "sk-ant-...", model: .claude35Sonnet)
let app = WritersApp(aiConfiguration: config)

// Enable adult mode (optional)
app.enableJulesAdultMode()

// Start chatting
var session = app.chatbotService!.startSession()

let response = try await app.chatbotService!.sendMessage(
    "Help me write gritty crime dialogue",
    in: &session
)

print("Jules: \(response)")

⚠️ DANGEROUS MODE - SKIP PERMISSIONS

Enable for Local Development:

  export DANGEROUS_MODE=true
  export SKIP_GIT_HOOKS=true
  export ANTHROPIC_API_KEY="sk-ant-..."

  swift run WritersAppCLI

What Gets Disabled:
  ✓ Git hooks (pre-commit validation)
  ✓ File permission checks
  ✓ Command execution approvals
  ✓ Sandbox restrictions
  ✓ All safety prompts

Git Commands to Skip Hooks:
  git commit --no-verify -m "message"
  git push --no-verify

WARNING: For local development only! Never use on shared machines.

🎬 EXAMPLE CONVERSATION

You: I'm writing a crime novel with a morally gray detective.
     How do I make her dialogue authentic?

Jules (Adult Mode): Hell, that's what makes noir compelling. Your detective should:
     1. Curse authentically - not every sentence, but when frustrated
     2. Speak frankly about sex, violence, corruption
     3. Use dark humor as a coping mechanism
     4. Say things "polite" people don't say
     5. Have a voice that's uniquely hers

     Want to workshop a specific scene?

You: Yeah, she's interrogating a suspect she knows is guilty but has no evidence

Jules: Perfect. Here's how to make it brutal and real:
     - Build tension through silence, not words
     - Use profanity strategically for impact
     - Show her desperation without begging
     - Include body language and subtext
     - Make the reader uncomfortable
